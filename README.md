# まなび4択問題データベース

小学1〜6年・国語／算数／せいかつA・B／理科／社会／英語の4択問題集。ゲームに組みこんで使う。

## チェック用アプリ

`index.html` は、問題の使い心地と内容を確かめるためのデバッグ用アプリ。GitHub Pages で <https://nochi-jpg.github.io/manabi-resource/> から遊べる。

- **クイズ**：全部ランダム → 学年 → 教科 → 単元の順にしぼりこんで出題する。
- **問題一覧**：学年・教科・単元・チェック状態・ことばでしぼりこめる。行をクリックすると、問題・答え・解説がポップアップで出る。
- **チェック**：どの画面でも「未チェック／問題なし／違和感あり」を切りかえられ、違和感メモを書ける（答える前でも書ける）。
- **チェック結果**：違和感ありの一覧。テキストでコピーするか、CSV・JSONで保存できる。

チェック結果はブラウザの中（localStorage）にだけ保存される。人に伝えるときは書き出して渡す。

## 使い方（ゲーム側）

`dist/` の中のどれか1つを読みこむ。

| ファイル | 中身 |
|---|---|
| `dist/questions.js` | `window.MANABI_QDB = {...}`（HTMLから `<script src>` で読む） |
| `dist/questions.min.json` / `questions.json` | 同じ内容のJSON |
| `dist/questions.csv` | 表計算ソフトで見る用 |

```js
MANABI_QDB.questions[0] = {
  id: "sa3-04-02",          // 教科コード＋学年-単元番号-問題番号（変わらない）
  subject: "算数", grade: 3,
  unitId: "sa3-04", unit: "あまりのあるわり算", area: "A 数と計算",
  q: "23÷5＝？",
  choices: ["4あまり3", "5あまり3", "4あまり2", "3あまり8"],   // 先頭が正解。表示するときにまぜる
  exp: "5×4＝20、23−20＝3。",
  kana: { q: "...", choices: [...], exp: "..." }              // ひらがなかたかなモード
}
MANABI_QDB.units  // 単元の一覧（問題数つき）。docs/UNITS.md にも同じ一覧
```

- **漢字モード**（`q` / `choices` / `exp`）：その学年までに習う漢字だけを漢字にし、まだ習わない字はひらがなにする。社会5・6年だけは、教科書と同じように用語・人名・地名を漢字で出す。1・2年は、言葉の切れ目に空白を入れる。
- **ひらがなかたかなモード**（`kana`）：漢字を使わない。ただし漢字の読み・書き・画数の問題では、問題の対象になっている漢字だけはそのまま出す。

教科コード：`ko` 国語／`sa` 算数／`la` せいかつA（社会寄り）／`lb` せいかつB（理科寄り）／`ri` 理科／`sh` 社会／`ei` 英語。

## 問題の数（2026年11月時点）

全 6,497 問・274 単元。学年・教科ごとの数は `docs/UNITS.md` を見る。

## 原稿の直し方

`dist/` は作られたファイルなので、手で直さない。直すのは次の原稿で、直したら `python3 tools/build.py` を実行する。

| 原稿 | 中身 | 作るツール |
|---|---|---|
| `src/<教科>/<学年>.txt`、`<学年>-b.txt` | 手書きの問題 | ― |
| `tables/*.txt` | 表から作る問題（地図記号・都道府県・歴史人物・年号・ことわざ・実験器具など） | `tools/gen_table.py` → `src/*/<学年>-tab.txt` |
| `tables/20-kanji-words.txt` | 漢字の読み・書きに使う言葉のリスト | `tools/gen_kokugo.py` → `src/ko/<学年>-gen.txt` |
| `tools/gen_sansu.py` | 計算問題（乱数の種は固定） | → `src/sa/<学年>-gen.txt` |
| `tools/gen_eigo.py` | 英単語の表 | → `src/ei/<学年>-gen.txt` |

```bash
python3 tools/gen_sansu.py && python3 tools/gen_eigo.py && python3 tools/gen_kokugo.py && python3 tools/gen_table.py
```

```bash
python3 tools/build.py
```

- `gen_kokugo.py` を動かすには `pip install pykakasi` が要る。
- 原稿の書き方（記法）は `tools/build.py` の先頭に書いてある。
- 問題IDは「単元の中で何番目か」で決まる。問題を足すときは単元の最後に足す（とちゅうに入れると、うしろの問題のIDがずれる）。

## 点検

`tools/build.py` は書き出すたびに、次のことを自動で調べる。

- 形がそろっているか（4択・解説あり・単元ごとの問題数）
- 選択肢の重なり：漢字モード・かなモードの両方で、同じ字・ほぼ同じ字・同じ値（`2/4` と `1/2`、`0.50` と `0.5` など、単位が同じもの）がないか
- 計算の答え：式の問題は計算しなおして、正解と合っているか
- 同じ問題文：かなモードにしたとき同じ文になるのに、答えがちがう問題がないか
- 習っていない漢字が、漢字モードに出ていないか
- 正解だけ長い・短い／正解が問題文に入っている（気づいたら直す。2択の比べる問題などは、そのままでよい）

`python3 tools/build.py --yomi` を使うと、ふりがなを辞書（pykakasi）と照らし合わせる。

### 人の目での点検（2026年11月）

- 手書きの約1,570問はすべて読み直した。
- 表と生成プログラムから作った問題は、表の1行ずつと、生成された問題の抜き出しを確かめた。
- 「こっちも正解では？」となりやすいものは、次のように直した。
  - 時代をまたぐ歴史人物（源頼朝・織田信長・徳川家康・西郷隆盛など）には「何時代？」を聞かない。
  - 同じ意味のことわざ（さるも木から落ちる／かっぱの川流れ）は、たがいにまちがいの選択肢にしない。
  - 2通りに読める言葉（雨雲・上下など）は、漢字の読みの問題に使わない。
- 年によって変わる統計の問題には、問題文か解説に年と出典を書いてある。新しい統計が出たら見直す。
  - 農産物の収穫量1位（`tables/10-shakai.txt` の社会5年 単元14）：果樹・米・さつまいもは農林水産省「作物統計」2025年（令和7年産）、野菜は同「野菜生産出荷統計」2023年（令和5年産）。公式資料で確かめられた品目だけを入れた。
  - 食料自給率：農林水産省「食料需給表」2025年度（カロリーベース 37％）。
  - 貿易相手国：財務省「貿易統計」2024年（輸出入の合計で中国が1位）。
  - 工業地帯の生産額：経済産業省「経済構造実態調査」2021年（中京工業地帯が1位）。
